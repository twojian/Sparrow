# t2a：训练与评测记录

本文只放"跑出来的东西"：三关验证的实测结果、8000 步那一次的完整记录、从它续训 2000 步那一次的记录，以及这两次运行的读法与边界。环境、录音数据、缓存、代码目录、一步训练、判分链路、参数表与坑都在 [05a-t2a-训练准备.md](05a-t2a-训练准备.md)，两篇不重复。

所有数字取自 `repro/work/runs/<run>/report.json` 的字段，不从日志目测。两次全量运行是各自独立的 run 目录，**不拼成一条曲线**（第 7 节专门说这条规矩）。

## 2. 第 1 关：`--eval_only`

在 `code\t2a\` 下执行：

```powershell
python sparrow.py --data ..\..\repro\work\data --cache ..\..\repro\work\cache --judges ..\..\repro\work\judges --eval_only --ckpt ..\..\repro\work\runs\t2a_full\final.pt --eval_tasks t2i,t2a --out ..\..\repro\work\runs\gate1
```

`--ckpt` 换成哪份权重，评的就是哪份。本轮实际跑的那次（`t2a_check_a`）用的是参考实现权重，不是上例里的 `t2a_full`。

| 观测值 | 期望 | 实测 | 对不上说明什么 |
| --- | --- | --- | --- |
| `report.json` | 在 `--out` 下生成 | 已生成 | 没生成：评测阶段抛异常，先看报错最后一行 |
| `eval_only.ckpt` | 记下被评的权重路径 | `code\t2a\weights\course_ep4\final.pt` | 缺失：跑的没进 `--eval_only` 分支 |
| `eval_only.ckpt_sha256` | 有值，且与该文件实测哈希一致 | `2b7dfe25…`，与文件哈希一致 | 不一致：权重在评测前后被换过 |
| `eval.t2a.sound_acc` | 有值且不为 0 | 94.58%（240 题） | 为 0 或缺失：Paraformer 没加载成功，或音频解码链断了 |
| `eval.t2a.exact_acc` | 有值 | 92.92% | 与 `sound_acc` 差距异常大：同音不同字变多 |
| `eval.t2i.both_acc` | 有值 | 100%（384 题） | 缺失：`--eval_tasks` 没带 `t2i`，或 `img.npz` 不在缓存里 |
| `samples\gen_t2a_*.wav` | 每个词至少一条，能播放 | 6 条已落盘，人工听辨未记录 | 有文件却放不出声：解码或采样有问题 |
| 耗时 / 峰值 | — | 353.3 s / 4.78 GB | 明显更长：多半在重新下载判卷器或 Mimi |

这一关的结论只能写到"用参考实现的已训权重跑通了评测链"——Paraformer 加载、音频解码、判分、样例落盘都发生了。**不写成"第 1 关已通过"**：算不算通过、以哪份权重为准尚未定；用本地权重单独跑一次 `--eval_only` 也没做过，本地权重的判分目前来自训练内评测（第 4、5 节）。

这份 94.58% / 92.92% 与续训末评同值，但来源不同：这里是参考实现权重，第 5 节是本地续训权重。逐词分布（0.925 / 0.975 / 0.900 / 0.925 / 0.950 / 1.000 对 1.000 / 0.900 / 0.975 / 0.850 / 1.000 / 0.950）与 13 条误听文本两两不同，分数相同属巧合，引用时不能混成一次运行。

## 3. 第 2 关：1 步冒烟与 10 步测速

```powershell
python sparrow.py ... --tasks t2i,t2a --steps 1  --eval_every 0 --bs 128 --out ..\..\repro\work\runs\t2a_smoke
python sparrow.py ... --tasks t2i,t2a --steps 10 --eval_every 0 --bs 128 --out ..\..\repro\work\runs\t2a_bench
python sparrow.py ... --tasks t2i,t2a --steps 10 --eval_every 0 --bs 256 --out ..\..\repro\work\runs\t2a_bench256
```

| 观测值 | 期望 | `t2a_smoke`（1 步） | `t2a_bench`（10 步，bs 128） | `t2a_bench256`（10 步，bs 256） | 对不上说明什么 |
| --- | --- | --- | --- | --- | --- |
| 首个 log 点 | 两个任务都有 loss | `t2i 1.9976 / t2a 1.9885` | 同左 | `t2i 2.0007 / t2a 2.0017` | 缺一项：任务没进 `--tasks`，或缓存缺零件 |
| `train_seconds` | 可读 | 2.1 s | 14.4 s（1.44 s/步） | 250.4 s（25.0 s/步） | 远超稳态：已进入显存回退 |
| `train_peak_mem_GB` | < 4.29 | 2.43 | 2.56 | 4.73 | 越线：批大小要退回去 |
| `eval_seconds` / `eval_peak_mem_GB` | 可读 | 89.6 s / 4.34 | 89.1 s / 4.34 | 85.3 s / 4.34 | 评测峰值不随 `--bs` 变，因为 `evaluate()` 内部批是写死的 |
| `exposure` | 步数 × 批 | 128 | 1280 | 2560 | 与 `steps × bs` 不等：有任务被跳过 |

读法：bs 128 时单步 1.44 s、峰值 2.56 GB，装得下；bs 256 时峰值 4.73 GB 已过 4.29 GB 线，单步 25.0 s 是 bs 128 的约 17 倍——这就是本机 `--bs 256` 的断崖，不是线性变慢，而是超出部分走 WDDM 内存回退，只慢不报错（口径同 [03a](03a-t2i-训练与评测.md) 第 6 节 Q2/Q3）。全量训练前 100 步 158.9 s（1.59 s/步），与这里的 1.44 s/步同量级，说明批量放大到 8000 步没有额外变慢。

这两组都是随机初始化，只回答"装得下、通不通、批能开多大"，不回答"学得动吗"；`t2a_smoke` 只评了 t2i（`eval.t2a` 为空），t2a 的判分要到第 3 关才有。

## 5. 第 3 关（续训）：12000 步里的后 2000 步

这是 `t2a_full` **结束之后另起的一次运行**，不是把第 4 节的表往后接一段：

```powershell
python sparrow.py ... --tasks t2i,t2a --steps 2000 --eval_every 1000 --bs 128 --init ..\..\repro\work\runs\t2a_full\final.pt --out ..\..\repro\work\runs\t2a_cont2k
```

## 7. 两次运行不能拼成一条曲线

规矩：8000 步那次与续训 2000 步那次是两个 run 目录，步数各自从 0 计，学习率各自重新 warmup + 余弦退火，数据顺序各自重新采样，曝光量也不连续（1,024,000 对 256,000）。所以：

- 说"91.67%"时必须带"8000 步那次"；说"94.58%"时必须带"在它之上再训 2000 步"。
- 不能写成"10000 步 94.58%"，也不能把第 4 节曲线与第 5 节末评点连成一条线。
- 训练损失同理：续训的 step 0 是 0.2562（t2a），接的是 8000 步末态的 0.2471 附近，不是从 1.9885 重来；两条损失曲线也不能拼。

显存越线只出现在评测阶段：训练 2.56 / 2.62 GB 都在 4.29 GB 线内；四次评测峰值 4.73 / 5.03 / 4.79 / 5.09 GB，越线 0.44–0.80 GB。超出部分由驱动的内存回退承担，只慢不报错（同 03a 第 6 节 Q2/Q3 的口径）。本轮没有"线内评测"的对照，无法量化这部分代价。

评测耗时不是"越训越快"：2000 步那次的 209.8 s 含图像 VAE、Mimi、Paraformer 的首次加载，之后几次才回落到 132–154 s。

## 8. 诚实边界

- **离参考线还差 2.92 点**：参考实现 `sound_acc` 97.5%，续训后 94.58%。主因是批大小——本地 `--bs 128`、参考 512；8000 步下本地看过约 102 万条样本（1,024,000），参考实现约 410 万条（4,096,000），只有对方的约 1/4。续训又多看了 25.6 万条，量级上仍补不平。
- **闭集 6 个词**：判分分不开"学会发音"与"记住这 6 个词"。8000 步 × 128 ÷ 1296 行 ≈ 790 个 epoch，词表只有 6 项，分数高不能直接外推成"能念新词"。
- **词间难度差稳定存在**：小兔、小鸟到 8000 步仍是最低（0.900 / 0.825），续训后小鸟仍垫底（0.850），说明不是全体都背了下来，但也不足以证明泛化。
- **三条来源不要混**：参考实现权重（`t2a_check_a`）、本地 8000 步（`t2a_full`）、本地续训 2000 步（`t2a_cont2k`）是三份不同权重，前者的 94.58% 与后者同值只是巧合。
- **未实测**：超过 12000 步（8000 + 续训 2000）的收益、换数据规模后的表现、评测越线对速度的定量影响（缺线内对照）。
