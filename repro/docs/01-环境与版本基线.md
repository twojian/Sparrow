# 环境与版本基线

本文锁定训练与推理链路所依赖的版本组合，并把「装什么、按什么顺序装、装完怎么验证」写成可复现的最短路径。对应代码在 `code/t2i/`，完整冻结清单见 [requirements-lock.txt](../requirements-lock.txt)。

结论先说：Python 3.12 + CUDA 12.6 运行时 + `diffusers 0.40.0` / `transformers 5.17.0` 的组合已跑通「VAE 编解码 → 数据编码 → 训练 → 评测 → 出图」全链路；`pip check` 无缺失，8 个入口脚本全部可编译。

## 1. 运行条件

| 项 | 基线 |
|---|---|
| 操作系统 | Windows 11 x64（原生，非容器） |
| Python | 3.12 |
| CUDA 运行时 | 12.6（`torch 2.9.0+cu126`） |
| 显存预算 | 4 GB 级单卡，无 Tensor Core |
| 依赖隔离 | 独立虚拟环境，不复用共享环境 |

显存预算是这套配置的核心约束：基线默认批大小 512 需要约 5 GB 峰值，本项目把批大小降到 128 并在 4 GB 预算内完成训练，见 [03a](03a-t2i-训练与评测.md)。

## 2. 依赖关系

安装顺序由依赖方向决定，不能打乱：

1. **CUDA 版 PyTorch 先装**。Windows 上 PyPI 的 `torch` 是 CPU 版，必须走 PyTorch 包索引取 `cu126` 轮子；后装的基础库若先解析到 CPU 版，需要整体重装。
2. **其余包按锁定版本一次装齐**。`diffusers 0.40.0` 与 `transformers 5.17.0` 是强版本钉：前者提供 `AutoencoderKLFlux2` / `AutoencoderKLWan`，后者提供 `MimiModel` / `SiglipVisionModel` / `WhisperModel`，版本漂移会直接改变缓存形状。
3. **冻结权重最后取**。图像 VAE 由 `frozen.py` 按固定仓库名加载，首次运行自动下载；换版本或换仓库等于换潜空间，已有编码缓存必须重建。

关键版本：

```
torch 2.9.0+cu126      torchvision 0.24.0+cu126
numpy 2.1.0            Pillow 11.3.0
diffusers 0.40.0       transformers 5.17.0
accelerate 1.15.0      huggingface-hub 1.32.0
soundfile 0.13.1
```

## 3. 安装步骤

```powershell
# 1) 独立环境
python -m venv .venv

# 2) CUDA 版 PyTorch（Windows 上 PyPI 的 torch 是 CPU 版，必须走 PyTorch 索引）
.\.venv\Scripts\python.exe -m pip install `
  torch==2.9.0 torchvision==0.24.0 --index-url https://download.pytorch.org/whl/cu126

# 3) 其余依赖（版本钉见 requirements-lock.txt）
.\.venv\Scripts\python.exe -m pip install -r repro\requirements-lock.txt

# 4) 冻结的图像 VAE（约 0.16 GB）
.\.venv\Scripts\hf.exe download `
  black-forest-labs/FLUX.2-klein-4B --include "vae/*"

# 5) 完整性检查
.\.venv\Scripts\python.exe -m pip check
```

## 4. 冒烟验证

| 验证项 | 结果 |
|---|---|
| `pip check` | `No broken requirements found.` |
| CUDA 可用性 | `torch.cuda.is_available() == True`，CUDA 12.6 运行时可用 |
| FP32 / FP16 / BF16 矩阵乘 | 三种 dtype 均可执行；BF16 在无张量核硬件上为软件模拟，故训练默认 bf16 只用于省显存、不提速 |
| VAE 类可用性 | `AutoencoderKLFlux2`、`AutoencoderKLWan` 均存在（diffusers 0.40.0） |
| 音频 / 视觉 / 语音编码器 | `MimiModel`、`SiglipVisionModel`、`WhisperModel` 均存在（transformers 5.17.0） |
| VAE 参数量 | 84.0M |
| VAE 编解码形状 | `64×64×3` → latent `(2, 32, 8, 8)` → 还原 `(2, 3, 64, 64)`，与 `frozen.py` 的 `ImageVAE` 路径一致 |
| 入口脚本编译 | `data.py`、`parts.py`、`world/world.py`、`train_judges.py`、`encode.py`、`frozen.py`、`sparrow.py`、`infer.py`、`ep3_assets.py` 全部 `py_compile` 通过 |

## 5. 已知约束

1. **原生 Windows 而非容器**：进程池并行与文件系统语义和 Linux 容器不同，造数据吞吐需实测，不按容器数值外推。
2. **无 Tensor Core**：bf16 为模拟实现、无张量核加速；FP16 需要 `GradScaler`，且实测更慢（见 [04](04-训练优化消融.md)）。
3. **显存预算低于基线默认批量**：训练批大小 512 不可用，固定为 128；评测解码批大小单独降为 64，两者理由不同。
4. **附加依赖延后安装**：`librosa`、`funasr`、`pypinyin` 只在 t2a 链路需要，避免污染主训练环境。
5. **数据与缓存体积**：完整训练集约 2.8 GB，图像编码缓存约 0.25 GB，属于单机可承载范围；缓存与数据不入库。
