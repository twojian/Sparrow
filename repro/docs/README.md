## 建议阅读顺序

1. **01** → 先确认依赖版本与安装顺序，后面所有数字都建立在这套环境上。
2. **02** → 数据怎么生成、判卷器怎么训、缓存长什么样。
3. **03a** → 主线的训练与评测，含耗时、显存与首张出图。
4. **03b** → 评测侧优化，一组改前改后对照。
5. **04** → 四轴消融，判断哪些手段真的有效、哪些只是看起来有效。
6. **05a** → t2a 的数据、缓存、一步训练与参数，回答"怎么准备"。
7. **05b** → t2a 三关的实测与两次运行的数字，回答"跑出来是什么"。

只想跑通链路，读完 01、02 即可按 [`../../code/t2i/README.md`](../../code/t2i/README.md) 操作；03a 之后是评测、优化与分析记录，不是执行前提。
